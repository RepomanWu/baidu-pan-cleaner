# 百度网盘清理助手

把网页版「垃圾文件清理」里的三项能力（扫描重复文件 / 扫描垃圾视频 / 扫描空文件夹）做成本地工具：扫码授权一次，之后双击启动、点几下就能扫描出报告，需要删除时再二次确认。

- 所有数据只保存在本机，不经过任何第三方服务器
- 每个账号独立保存登录态，可同时管理多个网盘账号
- 删除前必须在界面里勾选确认并输入「删除」，且只允许删除当前报告里出现过的路径

## 运行要求

- Windows 10/11
- Node.js 18 或更高版本（已安装则跳过）
- 本机已安装 Google Chrome（工具直接复用本机 Chrome，不额外下载浏览器内核）

## 首次使用

1. 双击 `启动.bat`。首次会自动安装依赖（约 5MB），随后自动打开 `http://127.0.0.1:5178`
2. 点左上角「+ 添加账号」，起个名字后点「创建并扫码授权」
3. 会弹出一个 Chrome 窗口，用手机百度网盘 App 扫码登录，登录成功后窗口会自动关闭
4. 选一个类型点「开始扫描」，等待进度条走完即可看到结果

命令行启动也可以：

```bash
npm install
npm start
```

## 多账号

再点一次「+ 添加账号」即可。每个账号的数据在 `data/profiles/<账号ID>` 下独立保存，互不影响；点账号卡片即可切换，历史报告也会按账号过滤。

## 授权用的浏览器

扫码授权时打开的是工具的独立浏览器窗口（默认 Edge），使用 `data/profiles/<账号ID>` 下的独立配置，不会读写你日常浏览器的账号、书签和扩展，也不会影响你正在用的窗口。

想换成 Chrome 打开，在 `data/config.json` 写入（没有该文件就新建）：

```json
{ "browser": "chrome" }
```

也可以用环境变量 `PAN_BROWSER=chrome` 临时指定；都不可用时脚本会自动回退到另一个浏览器。

## 扫描与删除

- **重复文件**：按内容分组，默认每组只勾选「修改时间最新」的那份之外的文件
- **垃圾视频**：默认全部勾选
- **空文件夹**：默认全部勾选
- 勾选只是标记，点「删除选中」后还会弹出确认框：必须勾选确认项并输入「删除」才会真正执行
- 删除后文件可在百度网盘回收站找回
- 建议扫描完尽快删除：删除依赖本次扫描的任务 ID，太旧的报告可能已过期，需要重新扫描
- 百度网盘对「删除清理项」有会员限制：超级会员可直接删除；普通账号可能被拒绝（错误码 131，提示「需要超级会员特权」）。此时仍可正常扫描和导出清单

## 报告

每次扫描都会在 `data/reports/` 生成一份 JSON 报告，界面里可以查看、导出 CSV / JSON，也可以删除报告（只删本地文件，不影响网盘）。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 提示「需要会员或试用名额」 | 百度网盘对清理功能有会员限制，非会员只能用试用次数 |
| 提示「删除清理项需要超级会员特权」 | 百度对删除动作的会员限制，当前账号无该权限；可扫描并导出清单，到网页/客户端手动处理 |
| 扫描结果只显示前 1500 项 | 界面渲染上限，完整数据在报告里，可导出 CSV；`MAX_ITEMS` 可调整抓取上限 |
| 提示「登录状态已失效」 | 点账号上的「重新授权」再扫一次码 |
| 点「扫码授权」没看到窗口 | 授权窗口可能被浏览器挡在后面，检查任务栏；授权会自动弹出二维码，误关窗口会立即提示重新授权 |
| 授权打开的是另一个浏览器窗口 | 工具用独立配置保存登录态（默认 Edge），不影响你日常浏览器；可在 `data/config.json` 指定 `browser` |
| 提示「Node.js not found」 | 未安装 Node.js；脚本会自动尝试常见安装路径，仍失败请装 Node.js 18+ |
| 扫描很慢 | 账号文件多时需要几分钟，工具会持续显示进度 |
| 重复文件结果非常多 | 报告会完整保存在本地，界面只渲染已加载部分；可先用 CSV 分析再回界面勾选 |
| 提示需要安全验证 | 在弹出的浏览器窗口里按提示完成验证，再重试 |

## 目录结构

```
bdpan-clean/
├─ 启动.bat            双击启动
├─ server.js           本地服务（127.0.0.1，仅本机可访问）
├─ core/pan.js         网盘接口与登录态管理（Playwright + 本机 Chrome）
├─ core/store.js       账号与报告存储
├─ core/jobs.js        任务状态
├─ public/             网页界面
└─ data/               运行时生成：accounts.json、profiles/、reports/
```

## 说明

工具调用的是网页版清理功能自身的接口：`/api/garbagescan`、`/api/garbagetaskquery`、`/api/garbagelist`、`/api/garbagedelete`。如果百度调整了接口，页面上的功能也可能同步变化，届时需要更新 `core/pan.js`。
